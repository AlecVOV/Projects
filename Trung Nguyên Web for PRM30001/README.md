# Trung Nguyen Coffee Website

A simple static website showcasing Trung Nguyen Coffee products, built for educational purposes.

## About This Project

This project is a basic static website created for **SWE40006 Software Deployment and Evolution** portfolio task. It demonstrates deploying a static website to **Azure Static Web Apps**.

## Features

- Product catalog (Packaged Coffee, Dispensing Tools, Premium Gifts)
- Top popular products section
- Customer reviews
- Responsive design
- Scroll reveal animations

## Tech Stack

- HTML5
- CSS3
- JavaScript
- [ScrollReveal.js](https://scrollrevealjs.org/)
- [Remix Icons](https://remixicon.com/)

## Deployment

This website is deployed on **Azure Static Web Apps** using GitHub Actions for CI/CD.

## Project Structure

```
├── index.html          # Main HTML file
├── styles.css          # Stylesheet
├── main.js             # JavaScript animations
├── assets/             # Images and media
└── .github/workflows/  # Azure deployment workflow
```
